# ELAM Santé Gabon 🇬🇦 (Application Python)
> **Système d'Information de Santé Médical & Épuré (Python / Flask / Jinja2 / SQLite / Tailwind CSS)**

---

## 📌 Caractéristiques du Nouveau Design

- **Zéro Émoji** : Remplacement systématique par des **icônes vectorielles SVG médicales nettes et professionnelles**.
- **Zéro Débordement de Texte** : Grille et typographie strictement proportionnées, conteneurs avec gestion des césures et affichage fluide sur tous les écrans.
- **Palette Médicale Sobre** : Blanc pur, vert chirurgical profond (`#0B6E4F`), ardoise et touches bleu institutionnel.
- **Base de Données Locale** : SQLite (`elam.db`) pré-remplie avec le réseau de santé gabonais (Libreville, Akanda, Glass, CHUL, Pharmacies de garde, Cardiologues, Pédiatres).

---
